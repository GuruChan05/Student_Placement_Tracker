# Student Placement Tracker

A simple web application to manage student placement records using **HTML, CSS, and JavaScript**.

## Features

* Add student records
* Edit and delete students
* Search by name, company, or role
* Filter by placement status
* Sort by name or package
* Calculate placement statistics
* Store data using LocalStorage
* Form validation

## Technologies

* HTML5
* CSS3
* JavaScript
* LocalStorage

## Project Structure


## JavaScript Concepts Used

* DOM Manipulation
* Events
* Arrays and Objects
* `push()`, `find()`, `filter()`, `map()`, `reduce()`, `sort()`
* LocalStorage
* JSON
* CRUD Operations
* Form Validation

## How to Run

1. Download or clone the project.
2. Open `index.html` in a browser.
3. Add and manage student placement records.
